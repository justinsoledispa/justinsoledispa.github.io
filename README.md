# Portafolio Académico — Justin Soledispa

Portafolio web personal para organizar y presentar proyectos académicos desarrollados durante la carrera. El sitio reúne trabajos por materia, tecnologías utilizadas, certificaciones y participaciones externas relacionadas con programación, bases de datos, estructuras de datos, sistemas y análisis de información.

## Sitio publicado

[Ver portafolio en GitHub Pages](https://justinsoledispa.github.io/)

## Contenido del portafolio

El portafolio está organizado en secciones principales:

* **Acerca de mí:** breve descripción del enfoque académico y técnico.
* **Proyectos por materia:** acceso a páginas internas con proyectos organizados por asignatura.
* **Tecnologías:** herramientas, lenguajes y recursos utilizados en los proyectos.
* **Certificaciones:** formación complementaria y credenciales verificables.
* **Hackatones:** participación en eventos externos como SpaceHACK 2026.
* **Contacto:** enlaces a GitHub, credenciales y correo académico.

## Proyectos destacados

### ATRIUM — Base de Datos I

Sistema de escritorio en JavaFX para gestionar eventos, emprendimientos, mentorías y reportes de un centro universitario de emprendimiento. Integra PostgreSQL, JDBC, carga de datos desde Excel y generación de reportes en PDF.

### Enreach DW/BI — Base de Datos II

Implementación de un Data Warehouse para análisis de información del ecosistema Enreach. Incluye procesos ETL, modelo dimensional, funciones SQL analíticas, API REST con Spring Boot y dashboards desarrollados con React.

### Blackboard — Estructura de Datos

Sistema académico en Java para gestionar estudiantes, actividades, entregas, calificaciones, consultas y reportes, aplicando estructuras de datos personalizadas.

### Agenda — Estructura de Datos

Aplicación de escritorio en Java para administrar contactos, realizar búsquedas y organizar información mediante estructuras como árbol de prefijos y heap.

### PeakNews — SpaceHACK 2026

Solución desarrollada en el contexto de SpaceHACK 2026. La propuesta aborda la verificación de información climática mediante análisis de datos, evidencia satelital y visualización de información relacionada con el cambio climático.
