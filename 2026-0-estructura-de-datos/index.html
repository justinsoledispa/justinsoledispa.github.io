Blackboard

Problema abordado

Gestionar estudiantes, actividades, entregas y calificaciones con consultas y reportes sin depender de hojas aisladas.

Solución desarrollada

Sistema académico en Java con estructuras personalizadas, cálculo de notas y exportación de reportes en TXT o CSV.

Mi aporte específico

Implementación de pilas para el procesamiento de calificaciones y menú de consultas en terminal.

Resultado obtenido

Aplicación funcional para consultar rendimiento académico, calcular resultados y generar archivos de salida.

Agenda

Problema abordado

Registrar y consultar contactos de forma eficiente, incluyendo búsquedas parciales y priorización por frecuencia.

Solución desarrollada

Aplicación Java de escritorio con carga/exportación CSV, árbol de prefijos y estructuras de prioridad.

Mi aporte específico

Implementación del Heap personalizado para ordenar contactos y funciones de búsqueda del TDA Aprefijo.

Resultado obtenido

Agenda funcional con búsqueda por prefijo, gestión de contactos y exportación de datos.

  • Árbol de prefijos
  • Heap
  • CSV
  • JavaFX
