FerreControl

Sistema distribuido para gestionar inventario de una ferretería. La aplicación web en Express y EJS se conecta a MySQL mediante una red privada Tailscale y coordina un sistema de reportes en un contenedor independiente.

Mi aporte: aplicación de inventario con Express/EJS, conexión MySQL, Docker y comunicación privada mediante Tailscale.

  • Express
  • EJS
  • MySQL
  • Docker
