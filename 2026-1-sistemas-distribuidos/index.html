FerreControl

Problema abordado

Gestionar inventario desde una aplicación web conectada a una base de datos remota y a un servicio de reportes separado.

Solución desarrollada

Aplicación Express + EJS con MySQL en Docker, comunicación por Tailscale y acceso visual a un sistema de reportes independiente.

Mi aporte específico

Aplicación de inventario, rutas Express, vistas EJS, conexión MySQL, Dockerfile y comunicación privada mediante Tailscale.

Resultado obtenido

Sistema distribuido funcional para registrar productos, actualizar stock, consultar historial y acceder a reportes externos.

  • Express
  • MySQL
  • Docker
  • Tailscale

Finalizado

MeshTask

Problema abordado

Gestionar tareas desde una aplicación web cuyo frontend debe comunicarse con un backend desplegado en otra máquina dentro de una arquitectura distribuida.

Solución desarrollada

Frontend React + Vite con Docker, Nginx, manifiestos Kubernetes y configuración de API en runtime para conectarse al backend mediante Tailscale + NodePort.

Mi aporte específico

Frontend y despliegue con Docker y Kubernetes.

Resultado obtenido

Aplicación con CRUD de tareas y categorías, filtros y búsqueda, estados y prioridades, estadísticas rápidas, diseño responsive, comunicación frontend/backend distribuida y configuración de API en runtime.

  • React
  • Docker
  • Kubernetes
  • Tailscale

CONCEPTOS

Conceptos aplicados

Conceptos principales aplicados en los proyectos publicados de la materia.

01 Contenedorización

Empaquetado de aplicación y base de datos en imágenes Docker con volúmenes persistentes para despliegues reproducibles.

02 Red privada distribuida

Comunicación segura entre servicios en máquinas físicamente distintas usando Tailscale como overlay de red sin exposición pública.

03 Orquestación

Despliegue de pods, Deployments y Services en Kubernetes para administrar réplicas del frontend React con NodePort.

04 Separación de servicios

Arquitectura donde frontend, backend y base de datos son procesos independientes que se comunican únicamente por API REST.
