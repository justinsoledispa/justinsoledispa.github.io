ATRIUM: Centro de Emprendimiento

Problema abordado

Organizar eventos, emprendimientos, mentorías y reportes de un centro académico sin depender de registros dispersos.

Solución desarrollada

Aplicación JavaFX conectada a PostgreSQL mediante JDBC, con carga masiva desde Excel y reportes exportables a PDF.

Mi aporte específico

Arquitectura Java, conexión con PostgreSQL y generación de PDFs para los reportes.

Resultado obtenido

Sistema académico funcional para consultar, registrar y reportar información del centro de emprendimiento.

CONCEPTOS

Conceptos aplicados

Conocimientos académicos trabajados durante el desarrollo del proyecto de la materia.

01 Diseño relacional

Normalización hasta 3FN y modelo entidad-relación para organizar eventos, emprendimientos y mentorías sin redundancia.

02 Transaccionalidad

Funciones almacenadas y control ACID en PostgreSQL para garantizar consistencia en cada operación de registro y reporte.

03 Persistencia con JDBC

Patrón DAO/DTO que desacopla el acceso a la base de datos de la lógica de presentación en la aplicación JavaFX.
